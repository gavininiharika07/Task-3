# Student Management System (C)

## 📌 Project Overview

The **Student Management System** is a simple console-based application developed in **C++**. It helps manage student records through an easy-to-use menu-driven interface. This project is suitable for beginners learning C++ programming, structures, functions, and vectors.

## ✨ Features

* ➕ Add Student
* 📋 Display All Students
* 🔍 Search Student by ID
* ✏️ Update Student Details
* ❌ Delete Student Record
* 🚪 Exit Program

## 🛠️ Technologies Used

* C
* Visual Studio Code
* GCC/G++ Compiler

## 📂 Project Structure

```
Student-Management-System/
```

## ▶️ How to Compile

```bash
g++ student_management.cpp -o student
```

## ▶️ How to Run

### Windows

```bash
student.exe
```

### Linux / macOS

```bash
./student
```
